# Code of Conduct

## Our commitment

We want this project to be a constructive environment for technical discussion and collaboration.

Participants are expected to:

- be respectful
- focus on technical issues
- welcome different perspectives
- provide constructive feedback
- avoid harassment or personal attacks

## Unacceptable behaviour

Examples include:

- harassment
- discrimination
- threats
- deliberate disruption
- publishing private information

Project maintainers may moderate discussions when necessary to keep the project constructive.

## Reporting

For serious issues, contact the project maintainer through the private contact mechanism listed in the repository profile.
